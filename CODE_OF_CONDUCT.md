# Code of Conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. The linked text is the authoritative version; this page summarises it and
names who to contact.

## Our pledge, in short

We want participation in this project — issues, pull requests, reviews, discussions — to be
harassment-free for everyone, regardless of age, body size, visible or invisible disability,
ethnicity, sex characteristics, gender identity and expression, level of experience, education,
socio-economic status, nationality, personal appearance, race, caste, colour, religion, or sexual
identity and orientation.

**Expected:** empathy and kindness; respect for differing opinions and experience; giving and
gracefully accepting constructive feedback; taking responsibility for mistakes and learning from
them; focusing on what is best for the community.

**Not acceptable:** sexualised language or imagery; trolling, insulting or derogatory comments;
personal or political attacks; public or private harassment; publishing others' private
information without explicit permission; any conduct reasonably considered inappropriate in a
professional setting.

## Scope

The code applies in every project space — this repository's issues, pull requests, discussions
and reviews — and when someone officially represents the project elsewhere.

## Reporting and enforcement

Report unacceptable behaviour privately to **conduct@your-domain.example** *(placeholder — the
maintainer replaces this with a monitored address)*. All reports are reviewed promptly and fairly,
and the reporter's privacy is respected.

Maintainers follow the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban, and permanent ban, according to the impact of the behaviour.

Security vulnerabilities are not conduct reports — see [SECURITY.md](SECURITY.md).
