# a reason is not allowed — the moment this file becomes a list of paths

# three legitimate reasons, and a new entry must fit one of them:
#
#   (1) GENERATED  — build_runner or a tool writes it; it is gitignored.
#   (2) SECRET     — credentials, deliberately never committed.

#                    name standing in for "your module here".
#
# Anything else is drift: fix the document instead.
